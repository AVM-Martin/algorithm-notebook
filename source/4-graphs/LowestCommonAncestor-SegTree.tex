Let LCA(r,u,v) be the LCA of u and v with respect to root r. To compute LCA(r,u,v), we can compute, for any fixed ro (let ro = 1), and take the "odd man out". Otherwise, take any one.
\begin{verbatim}
LCA(ro,r,u);    // LCA(1,r,u);
LCA(ro,r,v);    // LCA(1,r,v);
LCA(ro,u,v);    // LCA(1,u,v);
\end{verbatim}
